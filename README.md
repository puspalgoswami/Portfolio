## Run Locally

This portfolio is built with **HTML, CSS, and vanilla JavaScript**. No framework, package installation, or build step is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/puspalgoswami/Portfolio.git
   ```
2. Open the project folder:
   ```bash
   cd Portfolio
   ```
3. Open `index.html` in your browser, or launch the folder with the VS Code Live Server extension.
