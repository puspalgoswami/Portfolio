# Puspal Goswami — Portfolio

Updated personal portfolio using HTML, CSS and vanilla JavaScript. The existing visual direction is retained: a soft cyan hero, neutral page background, rounded white cards and clean typography.

## Apply to the existing GitHub repository
1. Download and extract `portfolio-refresh.zip`.
2. In your existing `Portfolio` repository, replace `index.html`, `style.css`, `script.js` and `README.md` with these files.
3. Keep the existing `assets/` folder unchanged. The page uses `assets/profile.jpg` for the profile portrait.
4. Commit and push the changes to `main` (or upload the files through GitHub's web interface).

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Notes
- No framework or build step is required.
- The site includes responsive navigation, reduced-motion support, and updated sections for skills, experience, projects, education, certifications and contact.
